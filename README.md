# Star Tracker

A Python-based star tracking pipeline that detects stars in an input image, submits it to the [Astrometry.net](https://nova.astrometry.net) plate-solving API, and uses the resulting WCS (World Coordinate System) solution to determine the direction of **Celestial North** — displayed as an arrow overlaid on the original image.

---

## Features

- Grayscale image loading and preprocessing with OpenCV
- Adaptive thresholding and connected component analysis for star detection
- Automated plate-solving via the Astrometry.net API
- WCS-based pixel-to-sky coordinate transformation using Astropy
- Celestial North direction vector calculation and visualization

## Setup

### 1. Get an Astrometry.net API Key

1. Create a free account at [nova.astrometry.net](https://nova.astrometry.net)
2. Go to your profile page and copy your API key

### 2. Set Your Image Path and API Key

In the notebook, locate these two placeholder lines and fill them in:

```python
img_path = "Images/Image1.jpg"      # Path to your input image

```

## Usage

Run the notebook cells **in order** from top to bottom:

1. **Image Processing and Star Detection** — Loads the image, applies adaptive thresholding, and detects star centroids using connected component analysis.
2. **Database Comparison** — Logs into the Astrometry.net API, submits the image for plate-solving, and downloads the WCS solution file (`solution.wcs`).
3. **Processing WCS File** — 
4. **Vector Calculation and Output** — Converts star pixel coordinates to RA/Dec using the WCS, computes the Celestial North direction vector, and draws it as an arrow on the image.

## Input & Output Images

Place your input star field images in the `images/` folder. The notebook will produce an annotated output image with:

- Detected stars highlighted with red circles
- A green arrow indicating the direction of **Celestial North**

Example output images are provided in the `outputs/` folder.

---

## Notes

- The Astrometry.net plate-solving step requires an internet connection and may take **several minutes** depending on server load.
- The full FITS file download is skipped intentionally — the WCS file contains all the coordinate transformation data needed, and the FITS file (~72MB) is unreliable to download due to server-side rate limiting.
- The `solution.wcs` file is a generated artifact and is excluded from version control via `.gitignore`.
